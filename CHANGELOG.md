# Changelog

All notable changes to ZetaReps. The app is no longer maintained; 1.0.4 is the final release.

## 1.0.4 — October 2026

- ZetaReps is now completely free: the Premium subscription and the 100-pushup limit are gone.
- Final release. The source code is published on GitHub under the MIT license.

## 1.0.3 — November 2025

- Time-dependent performance metrics.
- Sound effects.
- Rest days removed.
- Lowest metric band renamed from "needs work" to "poor".

## 1.0.2 — November 2025

- UI polish and fixes.

## 1.0.1 — November 5, 2025

- Release fixes.

## 1.0.0 — November 2, 2025

- Initial App Store release.
